# Finance Module API & Database Schema Documentation

## Database Schema Overview

The Finance module revolves around three key tables: `fee_structures`, `fee_invoices`, and `fee_payments`. Also, `parent_payment_requests` is used for online payment workflows.

### 1. `fee_structures`
Defines a specific fee (like "Tuition Fee", "Bus Fee") applicable to a certain academic year, grade, and term.
- `id` (UUID): Primary Key
- `school_id` (UUID): Reference to school
- `academic_year_id` (UUID): Reference to academic year
- `grade_id` (UUID): Reference to grade (nullable for generic fees)
- `term_id` (UUID): Reference to term (nullable for full-year fees)
- `category_id` (UUID): Fee Category
- `amount` (Decimal): The baseline amount
- `due_date` (Date): When the fee is due
- `is_mandatory` (Boolean): Whether all students must pay this fee

### 2. `fee_invoices`
Represents an actual bill issued to a student.
- `id` (UUID): Primary Key
- `school_id` (UUID): Reference to school
- `student_id` (UUID): Reference to student
- `structure_id` (UUID): Reference to `fee_structures`
- `academic_year_id` (UUID): Reference to academic year
- `term_id` (UUID): Reference to term
- `total_amount` (Decimal): The amount to be paid
- `paid_amount` (Decimal): Amount paid so far
- `status` (Enum): `pending`, `partial`, `paid`, `overdue`, `cancelled`
- `due_date` (Date): When the invoice is due

### 3. `fee_payments`
Represents a recorded transaction against an invoice or set of invoices.
- `id` (UUID): Primary Key
- `school_id` (UUID): Reference to school
- `invoice_id` (UUID): Reference to `fee_invoices`
- `student_id` (UUID): Reference to student
- `amount` (Decimal): Amount paid
- `payment_method` (Enum): `cash`, `card`, `upi`, `bank_transfer`, `online`
- `transaction_id` (String): Reference ID from payment gateway or bank
- `payment_date` (DateTime): When the payment occurred
- `status` (Enum): `completed`, `failed`, `pending`, `refunded`
- `remarks` (String): Optional notes

### 4. `parent_payment_requests`
Represents an online payment intent generated by a parent to pay multiple invoices at once via Razorpay.
- `id` (UUID): Primary Key
- `school_id` (UUID): Reference to school
- `parent_user_id` (UUID): Reference to the parent initiating payment
- `student_id` (UUID): Reference to student
- `invoice_ids` (JSONB): List of invoice IDs being paid
- `total_amount` (Decimal): Total amount to be paid
- `razorpay_order_id` (String): The Razorpay Order ID created
- `razorpay_payment_id` (String): The Razorpay Payment ID on success
- `razorpay_signature` (String): Verification signature
- `status` (Enum): `created`, `processing`, `completed`, `failed`

## API Endpoints

### Fees & Structures

#### `GET /api/v1/fees/categories`
Retrieve all fee categories.
- **Roles Allowed**: Any user

#### `POST /api/v1/fees/categories`
Create a new fee category.
- **Roles Allowed**: Admin, Principal

#### `DELETE /api/v1/fees/categories/:id`
Delete a fee category.
- **Roles Allowed**: Admin, Principal

#### `GET /api/v1/fees/structures`
Retrieve all fee structures. Filters available via query parameters.
- **Roles Allowed**: Any user

#### `POST /api/v1/fees/structures`
Create a new fee structure.
- **Roles Allowed**: Admin, Principal

#### `PUT /api/v1/fees/structures/:id`
Update a fee structure.
- **Roles Allowed**: Admin, Principal

#### `DELETE /api/v1/fees/structures/:id`
Delete a fee structure.
- **Roles Allowed**: Admin, Principal

---

### Invoices

#### `GET /api/v1/fees/invoices`
Retrieve all invoices for a school (with filtering by student, status, etc.).
- **Roles Allowed**: Any user

#### `POST /api/v1/fees/invoices/generate`
Bulk generate invoices based on a fee structure for all applicable students.
- **Roles Allowed**: Admin, Principal

#### `POST /api/v1/fees/invoices`
Create a manual invoice for a specific student.
- **Roles Allowed**: Admin, Principal

---

### Payments & Online Transactions

#### `POST /api/v1/fees/payments`
Manually record an offline payment (cash, bank transfer, cheque).
- **Roles Allowed**: Admin, Principal
- **Payload**:
  ```json
  {
    "invoice_id": "UUID",
    "amount": 1000.00,
    "payment_method": "cash",
    "transaction_id": "",
    "payment_date": "2024-01-01T00:00:00Z",
    "remarks": "Paid in office"
  }
  ```

#### `GET /api/v1/fees/payment-requests`
Retrieve parent payment requests (online transactions).
- **Roles Allowed**: Admin, Principal, Parent

#### `POST /api/v1/fees/payment-requests`
Initiate an online payment request via Razorpay. This returns the `razorpay_order_id` to be used in the checkout.
- **Roles Allowed**: Parent
- **Payload**:
  ```json
  {
    "student_id": "UUID",
    "invoice_ids": ["UUID_1", "UUID_2"],
    "total_amount": 2500.00
  }
  ```
- **Response**:
  ```json
  {
    "id": "UUID",
    "razorpay_order_id": "order_XXXXXX",
    "total_amount": 2500.00,
    "status": "created"
  }
  ```

#### `PUT /api/v1/fees/payment-requests/:id/decision`
Complete an online payment by providing verification signatures or marking it as failed.
- **Roles Allowed**: Admin, Principal, Parent
- **Payload (Success)**:
  ```json
  {
    "status": "completed",
    "razorpay_payment_id": "pay_XXXXXX",
    "razorpay_signature": "signature_XXXXXX"
  }
  ```
- **Payload (Failure)**:
  ```json
  {
    "status": "failed",
    "error_reason": "Payment cancelled by user"
  }
  ```
